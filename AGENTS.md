You are building LearnDojo, a production-grade full-stack learning platform.

Tech stack:
- Frontend: ReactJS + Vite + Tailwind CSS
- Backend: Node.js + Express.js
- Database: PostgreSQL with Prisma ORM
- Auth: JWT + refresh token
- Payments later: Stripe/Razorpay
- Storage later: S3/Cloudinary
- Code quality: ESLint, Prettier, Zod validation
- Testing: Vitest/React Testing Library for frontend, Jest/Supertest for backend

Product:
LearnDojo is a production learning platform, not a portfolio project.

Core roles:
1. Admin
2. Creator / Teacher / Writer
3. Learner / Student

Core modules:
1. Auth and role-based access
2. Roadmaps and roadmap nodes
3. W3Schools-style topic pages
4. Creator Studio
5. Admin content review workflow
6. Quizzes and attempts
7. StudyTracker
8. Doubt/Q&A system
9. Flashcards and revision system
10. Monetization-ready structure

Rules:
- Build production-quality code.
- Use clean folder structure.
- Never hardcode secrets.
- Add validation, error handling, loading states, empty states, and protected routes.
- Use reusable components.
- Keep API routes versioned under /api/v1.
- Every feature must include backend route, controller/service layer, validation, and frontend integration.
- Use GitHub issues and branches feature-by-feature.
- Before coding, create an implementation plan.
- After coding, run tests/lint and summarize changes.
