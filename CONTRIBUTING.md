# Contributing to LearnDojoWorld

Thank you for contributing.

## Project Direction

LearnDojoWorld is intended as a production-focused global learning platform.

Contributions should align with scalable architecture, learner experience quality, and secure engineering practices.

## Local Setup

```bash
pnpm install
pnpm dev
```

## Contribution Rules

- Use PNPM only.
- Do not commit real secrets or `.env` files.
- Keep authentication and RBAC secure.
- Preserve learner/creator/admin architecture boundaries.
- Keep schema and migrations production-safe.
- Update docs when setup or architecture changes.

## Pull Requests

Use the pull request template and include relevant implementation notes.
